# 求职信生成

请为求职者撰写一封针对{company}「{role}」岗位的求职信（{language}），长度一页以内。

【岗位描述】
{posting}

【求职者简历】
{profile_resume}

【求职偏好（用于判断薪资/公司类型等措辞）】
{preferences}

结构要求：
1. 称呼（尽量具体到人，未知用「尊敬的招聘负责人」）
2. 开头段：自我介绍 + 岗位来源渠道 + 为什么是这家公司（具体到业务/产品，不要空泛）
3. 主体段：2-4 个匹配点，量化优先；能力差距诚实说明学习路径
4. 结尾段：期待 + 行动（如何联系你）
5. 落款

硬性规则：
- 所有陈述只能来自简历材料，不得虚构
- 不用陈词滥调（"我非常热爱"类空话）
- 公司名与岗位名全文一致
