# Changelog

## [0.1.0] - 2026-08-20

### Added

- **E-Resume v0.1.0 首个版本** —— 原创的 AI 求职助手命令行工具：
  - `profile` 交互式建档向导（教育/经历/技能/语言/目标/硬性约束）
  - `prefs` 求职偏好向导（雇佣类型/薪资/公司类型/行业/地点/强度/成长，支持 `--section`）
  - 偏好门引擎：雇佣类型门、薪资门（含实习日薪智能处理）、公司类型门（含排除列表）、
    行业门、地点门、语言门——硬性不匹配直接拦截并引用依据
  - 匹配评分引擎：技术/经验/公司类型/职业方向/薪资 五维加权 + 结论与建议
  - 公司类型分类器：小而美/外企/大厂/潜力股/国企央企/外包（规则+关键词，标注依据）
  - `hr` 命令：HR 消息意图分类（面试邀请/笔试邀请/约时间/加微信/薪资沟通/拒信/已读不回…）
    + 回复草稿/角色扮演（基于真实材料，不虚构）
  - `cover`/`resume` 求职材料生成（提示词模式 + LLM 模式）
  - `interview` 面试准备包（含 HR 轮与薪资谈判要点）
  - `advice` 求职策略建议（定位/期望校准/渠道组合/行动计划）
  - `channels` 投递渠道图谱：18 个渠道（BOSS直聘/智联/51job/拉勾/猎聘/实习僧/牛客/
    内推/小众官网直投/国企央企/外包/外企官网…）官方入口、攻略、话术、风险提示与组合推荐
  - `apps`/`status`/`report` 投递记录与 HTML 仪表盘
  - 实习僧 Python 爬虫：NUXT 载荷解析（IIFE 参数映射替换方案）+ 图标实体剥离 +
    CONNECT 代理支持，搜索与详情真实可用
  - OpenAI 兼容 LLM 客户端（纯标准库 urllib），支持代理与自定义 base_url
  - 29 个单元测试（`python tests/run_tests.py`，零依赖运行器）
  - 中文 LaTeX 简历/求职信模板（xelatex + ctex）
